# Working on this project

This is a beginner learning project. Read PROJECT_NOTES.md for the next steps and the other two project ideas.

Keep changes small. Use simple Python, plain comments, and a short README. Explain new concepts before adding more features. Avoid adding dependencies unless they're needed for the current step.

Write the README as plain paragraphs with commands on their own lines. No badges, emojis, tables, callout boxes, or fenced code blocks. Keep the wording straightforward. End it with a concrete next step and update that step whenever work is completed.

Keep code comments short and useful. Explain a reason when needed; skip comments that just repeat the code or sound like a chat response. Apply these preferences to future updates too.

Use made-up sample data. Keep personal and lab data out of commits.

Run `python3 -m unittest -v` and `python3 checker.py sample.csv` before committing code changes.
